# Chrome Extension + Python Server RAG Project Plan

## Project Overview
This project consists of two main components:
1. A Chrome Extension that monitors visited URLs and provides search functionality
2. A Python FastAPI server that implements RAG (Retrieval Augmented Generation) for semantic search

## How the Plugin Works

### Automatic URL Processing
1. URL Monitoring:
   - Plugin automatically detects when user visits a new website
   - Extracts the current URL from the active tab
   - Checks if URL has been previously processed using chrome.storage
   - If URL is new, sends it to Python server via PUT API call
   - Stores processed URL in chrome.storage to prevent duplicate processing

2. Server-side Processing:
   - Server receives URL via /api/send_url endpoint
   - Uses MarkItDown to convert HTML content to clean text
   - Splits text into manageable chunks
   - Generates embeddings for each chunk
   - Stores chunks and embeddings in vector store
   - Returns success/failure status to extension

### Search Functionality
1. User Interface:
   - Extension popup contains a text input box
   - Submit button to trigger search
   - Loading indicator during API calls
   - Error messages for failed operations

2. Search Process:
   - User enters query in the text box
   - Clicks submit button
   - Extension sends query to /api/get_context endpoint
   - Server performs semantic search using query embedding
   - Returns 1-2 most relevant URLs and text chunks

3. Result Display:
   - Extension receives URLs and text chunks
   - Opens each URL in a new tab
   - Injects content script to highlight matching text
   - Scrolls to highlighted text automatically
   - Provides visual feedback for highlighted content

### Status Checking
1. URL Status Verification:
   - Extension can check if a URL has been processed
   - Calls /api/get_status endpoint with URL
   - Server checks if URL exists in vector store
   - Returns processing status to extension

## Component Details

### Chrome Extension Features
1. Automatic URL Monitoring:
   - Monitors every new website visit
   - Sends URL to Python server via PUT API call
   - Implements URL deduplication to prevent duplicate API calls
   - Uses chrome.storage to track processed URLs

2. Search Interface:
   - Input text box for user queries
   - Submit button to trigger search
   - Sends query to Python server via POST/PUT API
   - Displays loading state during API calls

3. Result Handling:
   - Receives 1-2 URLs and corresponding text chunks from server
   - Opens received URLs in new tabs
   - Highlights the specified text chunks in opened pages
   - Handles errors gracefully with user feedback

### Python Server Features
1. API Endpoints:
   - PUT /api/send_url: Receives and processes new URLs
   - POST /api/get_context: Handles user queries and returns relevant chunks
   - GET /api/get_status: Checks if a URL has been indexed

2. RAG Implementation:
   - Uses MarkItDown package for HTML to text conversion
   - Implements text chunking for better search results
   - Creates embeddings for semantic search
   - Maintains vector store for efficient retrieval
